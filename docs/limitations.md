# Ограничения и kolejne kroki (черновик для APP-26)

Список для документации конкурса (передаёт MD Mikicie Kutsence). Черновик собран по коду на 19.10.2026; перед отправкой проверить пункты, помеченные **[проверить]**.

## Известные ограничения

**Игра и честность**
- Очки начисляет приложение, а не сервер (без Cloud Functions, нужен тариф Blaze). Правила Firestore только ограничивают каждую запись: не больше +200 очков, очки и значки не уменьшаются, рейтинг совпадает с профилем. Серверная проверка — kolejne kroki.
- Hasło квеста и буквы лежат в приложении (`assets/demo/quest.json`) и в `questPlaces`, которые читает любой вошедший пользователь, поэтому hasło можно узнать, не посещая места.
- Проверка «не дальше 150 м от места» делается на телефоне по GPS; подменённую геолокацию она не распознаёт. Код места проверяют правила Firestore.
- Коды QR меняются вручную (`seed --new-codes`), после этого PDF печатается заново.
- После удаления аккаунта те же места можно отсканировать снова (решение Q-10).
- Около полуночи одно место можно отсканировать дважды: правила принимают и летнее, и зимнее польское время.
- Ranny ptaszek и Wieczorny spacerowicz считаются по алерту в момент старта маршрута: история алертов не хранится.
- Очки за подтверждённое zgłoszenie (+20) и значок Pomocnik miasta начисляются, когда пользователь открывает вкладку Odznaki после подтверждения в консоли Firebase.
- Код скидки MPK условный (одинаковый для пользователя, без связи с MigAppka).

**Данные и карта**
- Слои тени, зелени и шума — статические GeoJSON для Śródmieścia, пока у модуля D нет `/v1/layers` (DEP-04). В demo-режиме тень есть только для 14:30.
- Без `sunShareByHour` в ответе модуля D ползунок «Najlepsza pora wyjścia» скрыт; без `segments` линия маршрута одного цвета (DEP-03).
- Маршруты для произвольных точек в demo-режиме синтетические (с пометкой «Dla tego obszaru cień jest przybliżony»); точные — только две референсные трассы.
- Поиск адресов — Nominatim (OSM), только в границах Łodzi, не чаще 1 запроса в секунду.
- **[проверить]** Интеграция с реальным API модуля D: на 19.10 не проверена (APP-20, ждём DEP-05 и DEP-06). Если адреса не будет к подаче — приложение работает только на demo-данных.

**Алерты и push**
- Push об алерте отправляется вручную из консоли Firebase (тестовое сообщение); автоматической рассылки по данным IMGW нет — для неё нужна серверная часть.
- Режим жары на демо включается полем `config/game.heatOverride`.

**Платформа и интерфейс**
- Только Android 7.0+ (minSdk 24), только польский язык, только светлая тема, только портретная ориентация.
- Навигация шаг за шагом не делается в приложении: «Prowadź» открывает Google Maps (пешком, с промежуточными точками выбранной линии).
- Рейтинг видят только вошедшие пользователи приложения; сайт рейтинг не показывает (Q-03).
- **[проверить]** На реальных телефонах приложение ещё не проверено (APP-24); проверено автотестами (виджет-тесты на ширине 360 dp и в режиме Senior ×1,25, тесты правил Firestore в эмуляторе).

## Kolejne kroki

- Навигация шаг за шагом внутри приложения.
- Оценка маршрута после прогулки.
- AI-ассистент на естественном языке.
- Фото в zgłoszeniach, групповые прогулки, реферальный код, значки Ambasador и Wspólny spacer.
- Ещё 5 профилей комфорта отдельными карточками (пёс, коляска, дорога на работу, активный, чувствительность к шуму и смогу); их веса уже настраиваются ползунками.
- Вход через Google и другие аккаунты.
- Реальные коды MPK в MigAppka (нужно соглашение с MPK).
- Серверная проверка очков и сканов (Cloud Functions), автоматическая рассылка алертов IMGW.
- iOS, английский язык, тёмная тема.
